## Highlights

- Crop video with freeform drawing, aspect-ratio presets, or exact pixel controls. On desktop, open Crop beside the screenshot button or expand Crop in the Properties sidebar. On phones, choose Crop in the bottom action bar; settings appear below the preview, and the timeline hides to give the picture more room. Done returns to the cropped preview, and Remove crop restores the full frame. Crops are saved in drafts, support undo/redo and touch controls, and apply to video, GIF, and screenshot exports before resizing and subtitles.
- Edit more comfortably on phones with a larger preview and a bottom action bar for Trim, Subtitles, Crop, Playback, and More. Open subtitle controls when needed, adjust exact clip ranges in Trim, and expand track names from Timeline view. Pending edits, undo/redo history, and timeline position are preserved when switching tools or resizing the workspace.
- See which stage each media source has reached while playback loads: connecting, finding playback, or preparing playback details. Sources that are ready remain available while others continue loading.
- Connect to Plex servers faster when an earlier connection address is slow or unavailable by trying addresses in a staggered sequence.
- Get a confirmation before leaving the editor during an active export. Reloading or closing the tab also requests a browser warning.
- Export valid standalone FLAC files with short final frames in full. Cliparr continues to reject incomplete sources rather than silently exporting truncated audio.
- Improve timeline playback and scrubbing, including playback boundary and audio-context suspension behavior.

## Maintenance

Application dependencies and container images are updated. Container builds and deployment examples are hardened, and playback loading timings are available in the [logging guide](https://cliparr.dev/docs/logging#playback-loading-timings).

## Upgrade notes

Existing Docker commands and Compose files retain their configured port binding, data volume, and `APP_KEY`. If you replace your configuration with this repository's updated Compose file, it binds port 7171 to localhost by default. For remote access, set `CLIPARR_BIND_ADDRESS` to an appropriate host interface and use a VPN or authenticated reverse proxy. See [Access control](https://cliparr.dev/docs/access-control).

**Source builds and integrations:** The production, development, and capture Dockerfiles have been consolidated into `docker/Dockerfile` with corresponding build targets. Development provider profiles, volume ownership, and custom fixture checksum settings have also changed; see the [Docker guide](https://github.com/TechSquidTV/Cliparr/blob/main/docker/README.md) before updating a source checkout.

**Live playback integrations:** The source-state stream can now report `discovering` and `preparing`. Custom clients that exhaustively handle source states must accept these values.

If you are upgrading from 2.x, follow the [v3.0.0 migration instructions](https://github.com/TechSquidTV/Cliparr/releases/tag/v3.0.0) first.
