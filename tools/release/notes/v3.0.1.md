## Highlights

- Reduce memory use for video and audio exports in browsers with a native save picker by writing directly to disk. Cliparr and Cliparr Convert now ask you to choose the save location before processing starts. GIFs and browsers without the picker continue to download after export.
- GIF exports using **Compact** quality produce smaller files with the same appearance and timing.
- Screen readers announce editor slider labels and values, including units. More interface animations respect your device's reduced-motion setting.
- Restore rounded corners and opening animations on Cliparr Convert's dropdowns.

## Maintenance

Much of this release reorganizes the editor, export, and media-server code and removes duplicated logic. Dependencies and Docker images are also updated.

## Upgrade notes

No new data migration or configuration changes are required when upgrading from v3.0.0. If you are upgrading from 2.x, follow the [v3.0.0 migration instructions](https://github.com/TechSquidTV/Cliparr/releases/tag/v3.0.0) first.

When saving directly to disk, MP4, MOV, and M4A files place playback metadata at the end of the file. If you host these files for progressive playback, a player may need to fetch the end before playback starts. Files downloaded through the browser keep playback metadata at the beginning.
