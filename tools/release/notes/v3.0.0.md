## Highlights

- Export audio-only clips as MP3, M4A/AAC, Ogg/Opus, FLAC, or WAV. Your chosen video and audio formats are remembered, and exports support cancellation and retry. Processing stays in your browser.
- Use Cliparr Convert's audio templates to convert audio files or extract a video's soundtrack with one click to select the output format.
- Read clearer export summaries with labeled audio properties, easier-to-scan subtitle details, and shorter connection and export messages.
- Create, edit, and delete your own subtitles on local videos or provider media, even without a source subtitle track. Start blank or import dialogue, preview text as you type, and undo or redo subtitle changes. Authored text appears in previews, frame grabs, and video exports.
- See Plex and Jellyfin playback sessions update automatically when playback starts, pauses, or stops. Disconnected servers keep their last known sessions visible with a connection status, reconnect automatically, and offer **Retry connection**.
- Preserve source details, artwork, credits, and millisecond clip timing across supported video and audio containers. Local-file exports now receive clip timing even without provider metadata.
- Plex playback, audio-track selection, and subtitle imports are more reliable. This release also updates dependencies to address known security advisories.

## Breaking changes and upgrade notes

**Export existing drafts before upgrading.** Saved clip ranges and subtitle edits from earlier versions cannot be restored after upgrading. When you reopen provider media, Cliparr may import the preferred supported subtitle track again; local videos start without subtitles. Your original media, downloaded clips, and subtitle style preferences are preserved.

**Regular Jellyfin accounts require Jellyfin 10.11 or newer for live session updates.** Upgrade an older Jellyfin server or connect an administrator account. Plex session discovery still requires a server administrator account.

**Reverse proxies must support persistent notification connections.** Allow WebSockets between Cliparr and Jellyfin, and unbuffered server-sent events between Plex and Cliparr and between Cliparr and the browser. Review [reverse-proxy configuration](https://cliparr.dev/docs/configuration#reverse-proxies) if updates are delayed or connections repeatedly drop.

**Some Plex subtitle tracks may no longer be available for import.** Use SRT/SubRip or WebVTT when available. Other text formats require Plex to convert them for Cliparr. Some embedded text tracks become available after you select them during playback in Plex. See [Subtitle burn-in](https://cliparr.dev/docs/subtitle-burn-in#provider-notes).

**Tools that read embedded Cliparr metadata may need an update.** The metadata format has changed in 3.0. See [Export metadata](https://cliparr.dev/docs/export-metadata) for the fields included in your clips and the source upgrade notes below for integration changes.

**Mix down to stereo is enabled by default for video and audio exports.** Surround audio is converted to stereo; mono stays mono. The result can sound quieter than exports from earlier versions. Disable **Mix down to stereo** to keep supported surround channels with AAC or FLAC. MP3, WAV, and Opus exports currently require mono or stereo.

If you build Cliparr from source or maintain an integration, review the [3.0 source upgrade notes](https://github.com/TechSquidTV/Cliparr/blob/main/.github/CONTRIBUTING.md#upgrading-source-integrations-to-30).

## Audio export limitations

If a FLAC export fails because of the selected clip boundaries, choose WAV or adjust the start or end time. If a standalone FLAC file has an ending Cliparr cannot read, shorten the selection to end before that point; changing the output format will not recover the missing audio.

Exports remain in browser memory. Large audio exports show memory guidance, and WAV has a 4 GiB file-size limit. See [export settings](https://cliparr.dev/docs/export-settings) for browser codec, channel, and bit-depth support.
