Cliparr exports clips in the browser. Video and audio formats use Mediabunny, while GIF exports use Cliparr's optimized GIF encoder with worker-backed frame processing. Open the export dialog from the editor after choosing a clip range, then review the output settings, summary, and estimated size before saving the file.

## Export mode

Choose **Video** (default), **Audio**, or **GIF**. Video includes sound unless you enable **Mute audio** beside the dropdown. Audio hides the mute toggle and video quality, resolution, and subtitle controls. GIF shows quality and the resolved output dimensions without a format selector or audio controls. Video and audio formats, video mute and resolution, and separate video/GIF quality preferences are remembered while the editor is open.

## Format

| Format | Best for                                                  |
| :----- | :-------------------------------------------------------- |
| `MP4`  | Sharing, uploads, and general compatibility.              |
| `WEBM` | Efficient web playback.                                   |
| `MOV`  | Editing workflows that prefer QuickTime-style containers. |
| `MKV`  | Flexible container support.                               |

Codec availability depends on the browser and source media. If an export cannot keep the selected audio or video track in the chosen container, Cliparr stops the export and shows the reason instead of silently dropping important media.

Use `WEBM` instead of `GIF` when your destination supports video files. GIF is useful for compatibility with older platforms, but it has no audio, is capped at 15 seconds, and usually much larger than a modern video export.

Audio defaults to MP3 and groups its formats by compression:

| Format     | Best for                                 |
| :--------- | :--------------------------------------- |
| MP3        | Broad compatibility and sharing.         |
| M4A / AAC  | Efficient audio and editing.             |
| Ogg / Opus | Compact, high-quality audio.             |
| FLAC       | Compressed lossless audio, 16 or 24 bit. |
| WAV        | Uncompressed audio for editing.          |

Some FLAC edge cases, including single-frame clips and extremely small final compressed frames, are not supported by the current media library. Cliparr rejects these exports with an explanation. Choose WAV or adjust the clip boundaries; Cliparr does not pad audio or change its timing.

Standalone FLAC inputs can also have an unreadable tail. Cliparr rejects selections that include missing source audio before encoding or download, regardless of the chosen output format. A selection ending within the readable portion can still export. Changing the output to WAV does not recover unreadable input. This source-range restriction does not apply to FLAC audio inside MP4, MKV, or HLS sources.

Audio encoding settings are automatic. FLAC and WAV show the selected **Bit depth** marked **Auto**, with a visible explanation based on source precision and channel mixing. The summary shows the codec, channels, sample rate, bitrate or bit depth, and any necessary lossy resampling. FLAC and WAV do not silently change the source sample rate. Known integer sources up to 16 bit use 16-bit lossless output when only trimmed; processing or uncertain precision uses 24 bit. WAV can preserve identified 32-bit PCM. Higher precision sources cannot be silently reduced to FLAC.

## Quality

The `Quality` control is available for video and GIF exports. Video exports use
`Compact`, `Balanced`, and `Sharp`; GIF exports also include `Efficient` for a
smaller tuned animated-image preset.

| Quality     | Video behavior                                                                  | GIF behavior                                                           |
| :---------- | :------------------------------------------------------------------------------ | :--------------------------------------------------------------------- |
| `Compact`   | Forces a smaller, lower-bitrate transcode.                                      | 360p max, 10 fps, 64 colors.                                           |
| `Efficient` | Not shown for video exports.                                                    | 432p max, 12 fps, 128 colors with soft spatial and temporal dithering. |
| `Balanced`  | Forces a moderate-bitrate transcode for a smaller file than `Sharp`.            | 480p max, 12 fps, 128 colors with soft spatial and temporal dithering. |
| `Sharp`     | Preserves the source stream when possible, or uses the highest current default. | 720p max, 18 fps, 128 colors with soft spatial and temporal dithering. |

For video, `Sharp` is the safest choice when you want the closest match to the source. Use `Balanced` or `Compact` when file size matters more than preserving the original stream. For GIF, `Balanced` is the default because it preserves readable motion and detail. Choose `Efficient` when Balanced is slightly too large, or `Compact` when file size matters most. `Sharp` keeps the same tuned 128-color temporal dither but spends the file-size budget on higher resolution and smoother motion.

GIF clips longer than 15 seconds are blocked before export starts. Trim the range or choose `WEBM` for longer animated clips.

## Resolution

| Resolution | Behavior                                                             |
| :--------- | :------------------------------------------------------------------- |
| `Original` | Keeps the source dimensions when possible.                           |
| `1080p`    | Scales the output to 1080 pixels tall while preserving aspect ratio. |
| `720p`     | Scales the output to 720 pixels tall while preserving aspect ratio.  |

Use `Original` when you want the closest match to the source. Use `1080p` or `720p` when you want a smaller export for sharing or faster downloads.

GIF dimensions follow the quality preset's maximum height and preserve the source aspect ratio. Smaller sources keep their original dimensions. The GIF settings show the resolved dimensions instead of a resolution dropdown.

## Source

Cliparr may have more than one media path for the same item. The export source chooses which path Mediabunny reads when creating the final file.

| Source            | Behavior                                                                                                |
| :---------------- | :------------------------------------------------------------------------------------------------------ |
| `Auto`            | Chooses the best available path. It can use a direct fallback when HLS playback is not export-friendly. |
| `Direct/original` | Uses provider direct media, a local file, or a direct media URL when available.                         |
| `HLS playback`    | Uses the playback stream. This is useful when the playback stream is the only available export source.  |

For most clips, leave source on `Auto`. Choose a specific source when troubleshooting an export or when you intentionally want the playback stream rather than direct media.

## Audio

**Mix down to stereo** is enabled by default for both modes containing audio. Mono stays mono. Identified surround layouts include dialogue and surround contributions, omit LFE, and use headroom to avoid clipping. The resulting mix can be quieter than older exports. Disable mixdown to preserve channels when the selected codec and browser support their ordering; MP3 and WAV require mono or stereo in this release. Native Opus output also requires mono or stereo until its surround encoder mapping can be verified; AAC and FLAC preserve supported, identified layouts. Unsupported or unknown layouts produce an explanation rather than dropping channels.

## Estimated size

The export dialog shows an immediate estimated size in the footer before export starts. Cliparr resolves a planned output codec and numeric average bitrate from the selected format, quality, dimensions, and audio settings. `Sharp` exports preserve compatible source video when possible; otherwise they use the same planned target as the encoder.

Treat the value as approximate. Video uses variable bitrate, so exact output still depends on source motion, detail, browser codec behavior, GIF palette/dither behavior, and whether Cliparr can preserve the source track.

Audio size estimates use the resolved bitrate or WAV PCM parameters. FLAC size is shown as variable. Exports estimated at 100 MiB or larger show nonblocking memory guidance; this is not a browser memory guarantee. The completed file stays in browser memory, and WAV has a 4 GiB file-size limit.

## Filename templates

Filename templates are stored in your browser. Cliparr keeps separate defaults for movies and episodes, then fills available tokens from provider metadata and the selected clip range.

Default movie template:

```text
{source_title} ({year}) [{clip_start}-{clip_end}]
```

Default episode template:

```text
{show_title} - {episode_code} - {title} [{clip_start}-{clip_end}]
```

Available tokens:

| Token              | Notes                                               |
| :----------------- | :-------------------------------------------------- |
| `{title}`          | Item or clip title.                                 |
| `{source_title}`   | Source item title.                                  |
| `{show_title}`     | Series title for episode exports.                   |
| `{season_title}`   | Season title when available.                        |
| `{season_number}`  | Two-digit season number.                            |
| `{episode_number}` | Two-digit episode number.                           |
| `{episode_code}`   | Episode code such as `S02E05`.                      |
| `{year}`           | Source year when available.                         |
| `{clip_start}`     | Rounded clip start, formatted for filenames.        |
| `{clip_end}`       | Rounded clip end, formatted for filenames.          |
| `{clip_range}`     | Start and end together.                             |
| `{provider}`       | Provider id such as `plex`, `jellyfin`, or `local`. |
| `{item_type}`      | Item type such as `movie`, `episode`, or `video`.   |
| `{format}`         | Selected export format.                             |

Unsupported or missing token values resolve to empty text, and Cliparr sanitizes generated filenames for filesystem compatibility.

## Metadata

Audio and video clips preserve available title, show, season, episode, artwork, rating, credits, and source timing. Local files and direct URLs always receive clip timing, even without provider metadata. GIF exports do not embed metadata. See [Export metadata](/docs/export-metadata) for the full metadata table.
