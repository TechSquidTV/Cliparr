Provider-backed clips can include media-server metadata in the exported file, such as title, show, season, episode, artwork, rating, and timing details when the source provides them.

Connected sources are shared across the Cliparr instance. Connecting a regular Jellyfin account limits that source's sessions; it does not hide other connected sources. See [Access control](/docs/access-control) before sharing an instance.

<Callout title="Credentials stay encrypted" tone="info">
  Provider credentials are persisted so Cliparr can refresh sessions later. Keep
  `APP_KEY` stable so those credentials remain decryptable.
</Callout>

## Multiple sources

You can add more than one source, then disable or reconnect sources from source management. Cliparr shows available sessions from enabled sources and surfaces source-specific errors without blocking the rest of the dashboard.

## Automatic session updates

The dashboard subscribes to Plex and Jellyfin playback notifications. Starting, pausing, or stopping playback updates the dashboard automatically, without periodic session polling or a manual refresh. Cliparr loads an initial snapshot and resynchronizes after reconnecting.

If a connection drops, Cliparr keeps the last sessions visible, marks live updates as disconnected, and retries the connection automatically. **Retry connection** is available for failures. Expired credentials require reconnecting the source in **Sources**.

Reverse proxies must allow WebSocket connections between Cliparr and Jellyfin, and unbuffered server-sent events between Plex and Cliparr and between Cliparr and your browser. Persistent connections exchange keepalive messages; these do not poll for sessions.

<Callout title="Jellyfin compatibility change" tone="warning">
  Non-administrator accounts on Jellyfin versions older than 10.11 cannot use
  the live dashboard. Upgrade Jellyfin or connect an administrator account.
  Cliparr does not fall back to polling.
</Callout>
